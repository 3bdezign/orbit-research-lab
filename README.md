# Orbit — Roulette Research Lab

A local-first roulette research notebook for spin-history photographs, observation timing, physical-wheel records, and evidence-led statistical analysis.

The public website does not receive users' recorded observations or photographs. Browser storage (IndexedDB) is local to each device and origin; export backups regularly.

Deployed as a Render static site. Source: `index.html`, `sw.js`, `manifest.webmanifest`, and app icons.

Use only where observation/recording is permitted. The app does not claim a betting advantage.
